# 🔬 Wafer Map Pattern Intelligence

Deep learning classifier for WM-811K semiconductor wafer map defect patterns.
Built with TensorFlow/Keras, OpenCV, and Streamlit.

---

## Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Download the dataset
Download `LSWMD.pkl` from Kaggle and place it in the `data/` folder:
👉 https://www.kaggle.com/datasets/qingyi/wm811k-wafer-map

```
wafer-map-classifier/
└── data/
    └── LSWMD.pkl   ← place here
```

### 3. Train the model
```bash
python src/train.py
```
This will:
- Load and preprocess WM-811K
- Train a CNN for 50 epochs (early stopping)
- Save best model to `outputs/best_model.keras`
- Generate training curve plots

### 4. Evaluate
```bash
python src/evaluate.py
```
Generates in `outputs/`:
- `confusion_matrix.png`
- `classification_report.txt`
- `roc_curves.png`
- `top_misclassified.png`

### 5. Launch demo UI
```bash
streamlit run app.py
```
Opens at `http://localhost:8501`

### 6. Generate test images (optional)
```bash
python generate_test_input.py
```
Creates 9 synthetic wafer map images in `test_images/` — one per pattern class.

## Defect Pattern Classes (9)

| Class | Description |
|---|---|
| Center | Defects at wafer center |
| Donut | Ring-shaped band inside edge |
| Edge-Loc | Localized edge defects |
| Edge-Ring | Full peripheral defect ring |
| Loc | Isolated local cluster |
| Near-full | Nearly all dies failing |
| Random | No spatial pattern |
| Scratch | Linear defect trail |
| none | Clean wafer |

## Model Architecture

```
Input (64×64×1)
→ Conv2D(32) → BN → Conv2D(32) → BN → MaxPool → Dropout
→ Conv2D(64) → BN → Conv2D(64) → BN → MaxPool → Dropout
→ Conv2D(128) → BN → Conv2D(128) → BN → MaxPool → Dropout
→ GlobalAvgPool
→ Dense(256) → BN → Dropout(0.4)
→ Dense(128) → Dropout(0.3)
→ Dense(9, softmax)
```
